# baogames

Rust + Bevy 编写的儿童向 6 合 1 桌面小游戏合集。

## 运行

```bash
cargo run
```

## 游戏

- `1` 经典坦克：保护基地，击败敌方小坦克。
- `2` 炸弹迷宫：放置炸弹，清理软砖和机器人。
- `3` 泡泡龙风格：发射同色泡泡，清空顶部泡泡。
- `4` 竖版飞行：双人飞机射击，完成波次。
- `5` 横版射击：横版跳跃射击，到达终点。
- `6` 平台跳跃：收集星星，到达彩旗。

## 控制

- P1：`WASD` 移动，`J` 射击/放炸弹，`K` 或 `Space` 跳跃。
- P2：方向键移动，`Numpad1` 射击/放炸弹，`Numpad2` 或 `Right Shift` 跳跃。
- `Esc` 暂停/继续，结束后返回菜单。
- `Backspace` 从游戏返回菜单。

## 代码结构

- `src/main.rs`：程序入口，只启动游戏。
- `src/common/`：公共常量、输入映射、字体和基础绘制工具。
- `src/game/mod.rs`：Bevy app 组装、菜单、关卡生成和系统调度。
- `src/game/model.rs`：游戏状态、存档数据和 ECS 组件。
- `src/game/spawn.rs`：玩家、敌人、墙体、弹丸等实体生成。
- `src/game/rules.rs`：碰撞、炸弹范围、泡泡连通块等可单测规则。

## 素材

首版逻辑使用程序化彩色精灵兜底，方便先验证玩法和手感。外部可商用素材包应放入 `assets/vendor/`，并保留来源、许可证和替换说明。

中文文本使用 `assets/fonts/NotoSansCJK-Regular.ttc`，同时覆盖 ASCII、数字和中文，避免字体缺字导致框框或乱码。

当前推荐优先使用 Kenney 或 OpenGameArt 中允许商用的 2D 像素/卡通素材，不使用未授权的经典游戏原作素材。
