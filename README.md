# baogames

Rust + Bevy 编写的 6 合 1 桌面经典小游戏合集。当前版本使用程序化 2D 精灵和中文字体兜底，主菜单 6 张卡片、每款游戏拥有独立的玩法系统。

## 当前进度

- 主菜单展示 6 款经典：坦克大战、炸弹迷宫、太空射击、超级玛丽、魂斗罗、泡泡龙。按 `1`-`6` 选择，`Enter` 进入。
- 已实现：坦克大战、炸弹迷宫、太空射击。
- 占位（敬请期待）：超级玛丽、魂斗罗、泡泡龙。
- 已实现游戏的最高分 / 关卡解锁会写入项目运行目录下的 `baogames.save`。

## 游戏列表

- `1` 坦克大战：双人保护基地，摧毁 20 辆敌方坦克；包含砖墙、钢墙、水、草、冰、敌方刷新和玩家复活。
- `2` 炸弹迷宫：双人放置炸弹，炸开软砖、清理敌人、找到隐藏出口；包含火力、炸弹数量、速度、穿弹和遥控等道具。

  - 7 波杂兵编队 + 关底 BOSS。
  - 敌机分 5 种：侦察、狙击、轰炸、补给、BOSS；BOSS 三套弹幕模式（扇形、双侧瞄准、圆环）。
  - 三层视差星空背景，火力等级 1→3 通过击落红色补给机吃 P 道具升级。
  - 被击中扣 1 命并掉 1 级火力，重生短暂无敌闪烁。
- `4` 超级玛丽：敬请期待。
- `5` 魂斗罗：敬请期待。
- `6` 泡泡龙：敬请期待。

## 控制

- 菜单：`1`-`6` 选择并进入游戏，`Enter` 进入当前选中的游戏。
- P1：`WASD` 移动，`J` 射击 / 放炸弹，`K` 或 `Space` 跳跃。
- P2：方向键 移动，`Numpad1` 射击 / 放炸弹，`Numpad2` 或 `Right Shift` 跳跃。
- `Esc` 暂停 / 继续，游戏结束后返回菜单。
- `Backspace` 从游戏返回菜单。
- 游戏结束后按 `Enter` 重玩当前游戏。

太空射击仅使用 P1 操作；炸弹迷宫拿到遥控道具后，跳跃键会改为引爆遥控炸弹。

## 存档

通关会更新对应游戏的最高分，并解锁下一关，最高到第 10 关。删除 `baogames.save` 可重置进度。

## 代码结构

- `src/main.rs`：程序入口。
- `src/common/`：公共常量、输入映射、字体和基础绘制工具。
- `src/game/mod.rs`：Bevy app 组装、菜单、关卡分发与暂停 / 结束流程。
- `src/game/model.rs`：共享状态、存档数据和基础组件。
- `src/game/tank.rs`：坦克大战玩法系统。
- `src/game/bomb_maze.rs`：炸弹迷宫玩法系统。
- `src/game/space_shooter.rs`：太空射击玩法系统。

## 素材

首版逻辑使用程序化彩色精灵兜底，方便先验证玩法和手感。外部可商用素材包应放入 `assets/vendor/`，并保留来源、许可证和替换说明。

中文文本使用 `assets/fonts/NotoSansCJK-Regular.ttc`，同时覆盖 ASCII、数字和中文，避免字体缺字导致框框或乱码。

当前推荐优先使用 Kenney 或 OpenGameArt 中允许商用的 2D 像素 / 卡通素材，不使用未授权的经典游戏原作素材。
