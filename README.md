# baogames

Rust + Bevy 编写的儿童向 6 合 1 桌面小游戏合集。当前版本使用程序化 2D 精灵和中文字体兜底，优先验证本地双人玩法、关卡循环、分数和解锁进度。

## 当前进度

- 已接入 6 个小游戏入口，主菜单可按 `1`-`6` 直接进入。
- 已实现最高分和关卡解锁存档，存档文件为项目运行目录下的 `baogames.save`。
- 经典坦克和炸弹迷宫已拆成独立玩法系统，包含各自的 HUD、关卡规则、敌人和胜负流程。
- 其余玩法已具备可玩的原型循环，后续可继续替换素材和细化关卡。


## 游戏

- `1` 经典坦克：双人保护基地，摧毁 20 辆敌方坦克；包含砖墙、钢墙、水、草、冰、敌方刷新和玩家复活。
- `2` 炸弹迷宫：双人放置炸弹，炸开软砖，清理敌人，找到隐藏出口；包含火力、炸弹数量、速度、穿弹和遥控等道具。
- `3` 泡泡龙风格：移动发射器，发射同色泡泡，清空顶部泡泡。
- `4` 竖版飞行：双人飞机射击，躲避来袭敌机，坚持完成倒计时。
- `5` 横版射击：双人横版跳跃射击，清理挡路机器人并抵达终点。
- `6` 平台跳跃：双人平台跳跃，收集星星并到达彩旗。

## 控制

- 菜单：`1`-`6` 选择并进入游戏，`Enter` 进入当前选中的游戏。
- P1：`WASD` 移动，`J` 射击/放炸弹，`K` 或 `Space` 跳跃。
- P2：方向键移动，`Numpad1` 射击/放炸弹，`Numpad2` 或 `Right Shift` 跳跃。
- `Esc` 暂停/继续，游戏结束后返回菜单。
- `Backspace` 从游戏返回菜单。
- 游戏结束后按 `Enter` 重玩当前游戏。

炸弹迷宫拿到遥控道具后，跳跃键会改为引爆遥控炸弹。

## 存档

通关会更新对应游戏的最高分，并解锁下一关，最高到第 10 关。删除 `baogames.save` 可重置进度。

## 代码结构

- `src/main.rs`：程序入口，只启动游戏。
- `src/common/`：公共常量、输入映射、字体和基础绘制工具。
- `src/game/mod.rs`：Bevy app 组装、菜单、关卡生成和系统调度。
- `src/game/model.rs`：游戏状态、存档数据和 ECS 组件。
- `src/game/spawn.rs`：玩家、敌人、墙体、弹丸等实体生成。
- `src/game/tank.rs`：经典坦克玩法系统。
- `src/game/bomb_maze.rs`：炸弹迷宫玩法系统。
- `src/game/rules.rs`：碰撞、炸弹范围、泡泡连通块等可单测规则。

## 素材

首版逻辑使用程序化彩色精灵兜底，方便先验证玩法和手感。外部可商用素材包应放入 `assets/vendor/`，并保留来源、许可证和替换说明。

中文文本使用 `assets/fonts/NotoSansCJK-Regular.ttc`，同时覆盖 ASCII、数字和中文，避免字体缺字导致框框或乱码。

当前推荐优先使用 Kenney 或 OpenGameArt 中允许商用的 2D 像素/卡通素材，不使用未授权的经典游戏原作素材。
