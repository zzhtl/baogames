# baogames

Rust + Bevy 编写的 8 合 1 桌面经典小游戏合集。项目使用原创程序化像素精灵与芯片音乐，在不复制原作素材的前提下重现经典玩法与手感。

## 当前进度

- 2×4 卡带墙展示 8 款经典：坦克大战、炸弹迷宫、太空射击、超级玛丽、魂斗罗、泡泡龙、记忆翻翻乐、推箱子。
- 8 款全部可玩。
- 默认使用 4:3 的 240×180 像素画布，可切换 16:9；最近邻整数放大，并可选 CRT 扫描线与轻微震屏。
- 支持经典 / 辅助两种玩法。超级玛丽与魂斗罗辅助模式提供 6 个固定帧的跳跃缓冲、5 帧土狼时间；超级玛丽另有落地检查点。
- 最高分、已解锁关卡、自由选关位置、画面/音频/按键设置写入版本化存档；旧版存档会自动迁移。

## 游戏列表

- `1` 坦克大战：60Hz 固定模拟，支持单人/双人保护基地并摧毁 20 辆敌方坦克；包含路口预转向、冰面惯性、敌我炮弹对消、可视护盾、基地危机提示、砖墙、钢墙、水、草和六种道具。
- `2` 炸弹迷宫：60Hz 固定模拟与经典四向网格移动，双人逐次放置炸弹、连锁引爆、炸开软砖并寻找隐藏出口；包含火力、炸弹数量、速度、穿弹和遥控等道具。
- `3` 太空射击（雷电 / 1942 风格）：单人 P1 操控战机，以 60Hz 固定模拟由下而上推进；动作二可消耗次数进行无敌翻滚。
  - 7 波杂兵编队 + 关底 BOSS。
  - 敌机分 5 种：侦察、狙击、轰炸、补给、BOSS；BOSS 三套弹幕模式（扇形、双侧瞄准、圆环）。
  - 三层视差星空背景，火力等级 1→3 通过击落红色补给机吃 P 道具升级。
  - 被击中扣 1 命并掉 1 级火力，重生短暂无敌闪烁；命中火花、枪口火光、动态爆炸和分段 Boss 血条强化战斗反馈。
- `4` 超级玛丽：四个连续关卡，60Hz 固定物理；包含地上、地下、天空与城堡场景，踩敌、成长、火球、移动平台、旗杆和 Bowser 战。
- `5` 魂斗罗：60Hz 固定物理、8 方向射击、卧倒与空中翻滚；包含五种武器、程序化敌兵节奏，以及只能攻击能量核心的关底要塞 BOSS。
- `6` 泡泡龙：60Hz 固定模拟，旋转炮台瞄准发射，带反弹轨迹与落点预览；三连同色消除、连续消除奖励，浮空泡泡会带旋转惯性掉落。
  - 关卡 1→10 颜色数 3→6、起始行 4→10、未消步数阈值 12→6，逐步加压。
  - 左右调整炮口角度，动作一发射并支持短暂输入缓冲；炮口左侧显示「下一发」，天花板下移和死亡线危险均有动态提示。
  - 计分：三连+50/颗，5 连及以上额外加 30/颗（超出 4 颗的部分），浮空掉落 100/颗，通关额外 +1000。
- `7` 记忆翻翻乐：60Hz 固定逻辑，开局先短暂展示全部牌面，再用带中点换面的翻牌动画完成配对；连续配对有递增奖励，关卡越高牌越多、时间越紧。
- `8` 推箱子：60Hz 固定逻辑与平滑格间移动，把所有箱子推到目标点；动作二逐步撤销，重置键重来，误推入非目标死角时会即时警告；十个关卡从易到难。

## 控制

- 菜单：方向选择卡带，动作一进入自由选关，动作二进入设置，开始键进入游戏。
- P1 默认：`WASD` 移动，`J` 动作一，`K` 动作二，`Enter` 开始/暂停，`Backspace` 返回，`R` 重置。
- P2 默认：方向键移动，`Numpad1` 动作一，`Numpad2` 动作二，`NumpadEnter` 开始，`Delete` 返回，`Numpad0` 重置。
- 键盘和手柄的九个语义动作均可在“系统设置 → 按键配置”中为 P1 / P2 独立重映射；同一玩家的冲突键位会自动交换。
- 胜利后动作一 / 开始键连续进入下一关；失败时重试当前关；返回键回到卡带墙。

太空射击仅使用 P1 操作；炸弹迷宫拿到遥控道具后，跳跃键会改为引爆遥控炸弹。

## 存档

通关会更新对应游戏的最高分并解锁下一关。超级玛丽共 4 关，其余游戏最高 10 关；卡带墙可在已解锁范围内自由选关。删除 `baogames.save` 可重置进度。

## 代码结构

- `src/main.rs`：程序入口。
- `src/lib.rs`：库入口，供游戏本体与离线预览工具共享代码。
- `src/common/`：公共常量、输入映射、字体、SpriteDef 精灵定义和基础绘制工具。
- `src/bin/preview/`：离线精灵预览工具，把游戏在用的 SpriteDef 渲染成 PNG（`cargo run --bin preview`）。
- `src/game/mod.rs`：Bevy app 组装、菜单、关卡分发与暂停 / 结束流程。
- `src/game/model.rs`：共享状态、存档数据和基础组件。
- `src/game/tank/`：坦克大战玩法系统。
- `src/game/bomb_maze/`：炸弹迷宫玩法系统。
- `src/game/space_shooter/`：太空射击玩法系统。
- `src/game/super_mario/`：超级玛丽玩法系统。
- `src/game/contra/`：魂斗罗玩法系统。
- `src/game/bubble_shooter/`：泡泡龙玩法系统。
- `src/game/memory_match/`：记忆翻翻乐玩法系统。
- `src/game/sokoban/`：推箱子玩法系统。

## 音频

全部音频由代码生成，无外部录音或原作旋律。射击、爆炸、跳跃、金币、配对、胜负等事件使用方波 / 三角波 / 噪声音效；菜单和八款游戏各有一首原创 8-bit 循环曲。音乐与音效音量可分别调整。

## 精灵预览

`SpriteDef` 精灵与离线预览工具同源，改精灵前可先出图确认：

```bash
cargo run --bin preview                     # 渲染全部游戏精灵
cargo run --bin preview -- contra prone     # 魂斗罗卧倒姿态
cargo run --bin preview -- tank p1          # 单个精灵：x8 放大图 + 实机尺寸图
cargo run --bin preview -- memory back      # 记忆翻翻乐卡背
cargo run --bin preview -- soko box         # 推箱子木箱
cargo run --bin preview -- compare a.png b.png out.png   # 与参考图并排
```

产物写到 `preview_out/`。

## 素材

游戏画面使用仓库内的原创程序化像素精灵，不包含经典游戏原作图像或音乐。中文界面使用 Fusion Pixel Font 2026.07.01 的 12px 比例简体版本，按 SIL OFL-1.1 授权；来源和许可证见 `assets/fonts/README.md` 与 `assets/fonts/OFL.txt`。
